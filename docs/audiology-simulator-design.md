# 听力学本科测听学习模拟工具开发文档

版本：v0.1  
日期：2026-06-10  
状态：开发前设计稿  
目标用户：听力学专业本科生、带教教师、实验课管理员

## 1. 项目定位

本项目拟开发一个面向听力学专业本科教学的测听学习模拟工具。学生在浏览器中操作模拟测听设备，对模拟患者进行问诊、检查准备、纯音测听、必要时的掩蔽判断与测试，系统根据隐藏的患者听力学参数生成患者反应、记录学生操作过程，并输出模拟测试报告、评分与教学反馈。

本工具用于教学训练和考核，不用于真实临床诊断、真实设备校准、职业健康筛查结论或医疗处置建议。所有报告应明确标注“模拟病例 / 教学用途”。

## 2. 设计目标

1. 让本科生在无真实患者压力的环境中反复练习常规纯音测听流程。
2. 模拟“设备参数选择 -> 给声 -> 患者反应 -> 阈值判断 -> 记录听力图”的实际工作节奏。
3. 帮助学生理解气导、骨导、交叉听觉、掩蔽、无反应、可靠性和听力图解释之间的关系。
4. 为教师提供病例库、考核模式、过程日志、评分细则和教学复盘材料。
5. 保持病例可扩展，后续能逐步加入言语测听、声导抗、耳声发射等模块。

## 3. 使用角色

| 角色 | 主要任务 |
| --- | --- |
| 学生 | 选择练习或考试病例，操作模拟设备，完成测试和报告，查看反馈。 |
| 教师 | 创建病例、配置课程、发起考核、查看学生过程日志和成绩。 |
| 管理员 | 维护班级、账号、题库、评分方案和数据导出。 |
| 模拟患者引擎 | 根据病例参数、学生操作、患者可靠性生成反应和行为。 |

## 4. MVP 范围

第一阶段优先实现“纯音测听教学闭环”：

- 模拟双通道纯音听力计界面。
- 模拟标准隔声室和患者响应按钮。
- 模拟成人/较大儿童常规气导、骨导纯音阈值测试。
- 支持右耳、左耳、气导、骨导、窄带噪声掩蔽。
- 自动绘制听力图，记录测试事件。
- 根据学生操作生成模拟报告。
- 支持练习模式、考试模式、教师评分规则。
- 内置一批典型教学病例。

第一阶段暂不做：

- 真实硬件接入。
- 医疗机构电子病历对接。
- 真实患者数据导入。
- 临床诊断自动化建议。
- 复杂儿科行为测听。
- 声场测听、助听器验配验证、高频测听。

## 5. 核心学习任务

学生应能在工具中完成以下任务：

1. 读取病例基本信息和主诉。
2. 进行测前准备：问询近期噪声暴露、耳鸣、较好耳、佩戴物、助听器、耳镜结果等。
3. 正确向患者说明任务，并确认患者理解。
4. 选择换能器：耳机、插入式耳机、骨导振子。
5. 选择测试耳、频率、强度、持续时间、给声方式。
6. 使用上升法寻找阈值，能识别可疑反应和假阳性/假阴性。
7. 完成常规气导频率点测试，必要时复测 1000 Hz。
8. 完成骨导测试，理解非耳特异性骨导结果。
9. 判断是否需要掩蔽，并能使用教学版平台法完成掩蔽练习。
10. 标记无反应、掩蔽阈值、可疑可靠性和测试备注。
11. 生成结构化报告，包括听力图、阈值表、结果描述、可靠性说明和学习反馈。

## 6. 典型用户流程

### 6.1 练习模式

1. 学生进入课程，选择病例难度。
2. 系统展示患者头像、年龄、主诉、病史摘要和可选测前检查信息。
3. 学生进入模拟测听室界面。
4. 学生设置测试参数并给声，患者根据隐藏阈值和行为模型响应。
5. 系统实时绘制工作听力图，也可允许学生手动记录。
6. 学生提交报告。
7. 系统显示标准答案、操作轨迹、错误点、知识解释和建议重练项目。

### 6.2 考试模式

1. 教师发布考试病例组和时间限制。
2. 学生仅看到必要病例信息，不显示实时提示。
3. 系统记录完整事件日志，不在考试中展示标准答案。
4. 学生提交后生成模拟报告。
5. 评分引擎根据过程、结果和解释自动评分，教师可人工复核。

### 6.3 教师复盘

1. 教师查看班级成绩分布。
2. 按病例查看常见错误：漏测频率、掩蔽判断错误、阈值确认不足、报告解释错误等。
3. 打开某个学生的测试回放，按时间轴查看每次给声和患者响应。
4. 导出成绩、报告 PDF 和事件日志。

## 7. 功能模块

### 7.1 模拟测听设备

设备界面应尽量贴近教学实验室中的临床听力计，但交互要适合网页：

- 双通道控制：Channel 1 纯音，Channel 2 掩蔽噪声。
- 测试耳选择：右耳、左耳、双耳/禁用。
- 换能器选择：气导耳机、插入式耳机、骨导振子。
- 频率选择：125、250、500、750、1000、1500、2000、3000、4000、6000、8000 Hz；MVP 可默认显示常规频率。
- 强度选择：-10 到 120 dB HL，按设备和频率设置最大输出限制。
- 步进：5 dB 为主，支持 10 dB 快速调整。
- 刺激方式：连续、脉冲、啭音或纯音；MVP 可先实现纯音/脉冲切换。
- 给声按钮：按住给声、点击给声两种交互。
- 患者响应灯：显示按键响应、响应延迟、释放时间。
- Talk-back / Talk-over：MVP 可用预设话术按钮模拟。
- 校准/环境状态：显示“教学模拟校准通过”“环境噪声水平”等，不代表真实校准。

### 7.2 模拟患者

每个病例由隐藏听力参数和显性病例信息组成。

显性信息：

- 年龄、性别、学习用编号。
- 主诉：听不清、耳鸣、噪声暴露、单侧耳闷等。
- 简要病史：起病时间、进展、职业/娱乐噪声、耳病史、家族史。
- 测前检查提示：耳镜、耳道耵聍、鼓膜外观、近期噪声暴露、佩戴助听器等。
- 合作程度：配合、紧张、疲劳、反应慢、不稳定、疑似功能性夸大等。

隐藏参数：

- 左右耳真实气导阈值。
- 左右耳真实骨导阈值。
- 频率相关耳鸣干扰。
- 响应延迟分布。
- 假阳性概率、假阴性概率。
- 疲劳曲线和注意力下降。
- 可学习性：说明越清楚，错误响应越少。
- 最大可耐受声级或不适提示。

### 7.3 患者反应引擎

患者反应应具有“可解释的随机性”，既不能机械到每次完全一致，也不能随机到破坏教学目标。

基础逻辑：

- 给声低于实际可听阈值时，患者一般不响应，但可能出现假阳性。
- 给声高于阈值越多，响应概率越高、响应延迟越短。
- 接近阈值时，响应概率处于不稳定区间。
- 患者状态差、耳鸣明显、指令不清或测试时间过长时，可靠性下降。

建议模型：

```text
sensationLevel = presentedLevel - effectiveThreshold
baseProbability = sigmoid((sensationLevel - 2) / slope)
responseProbability = baseProbability * attentionFactor * instructionFactor
responseProbability -= falseNegativeRisk
responseProbability += falsePositiveRiskWhenNoTone
```

交叉听觉和掩蔽：

- 气导未掩蔽时，若测试耳给声强度经耳间衰减后仍可被非测试耳听到，应产生交叉听觉风险。
- 插入式耳机和压耳式耳机使用不同的教学化耳间衰减默认值。
- 骨导未掩蔽结果默认视为非耳特异性，应允许学生在报告中说明。
- 掩蔽噪声会提高非测试耳对测试信号的有效阈值；MVP 可采用简化平台法模型，并在教学解释中明确是训练模型。

### 7.4 听力图与记录

系统应支持：

- 标准听力图坐标：横轴频率按对数间距，纵轴 dB HL 向下增大。
- 右耳、左耳、气导、骨导、掩蔽、无反应等符号。
- 阈值表格和图形同步。
- 工作听力图：记录学生每次尝试和最终确认阈值。
- 掩蔽图/掩蔽记录：记录每个频率的噪声水平和平台判断。
- 备注：耳鸣影响、患者疲劳、无反应、可疑可靠性、环境噪声等。

### 7.5 报告生成

模拟报告至少包含：

- 报告标题和“教学模拟”标识。
- 学生、病例编号、测试日期、模式。
- 模拟设备配置和换能器。
- 气导/骨导阈值表。
- 听力图。
- 平均听阈：三频 PTA，可扩展四频 PTA。
- 听力损失程度、性质和构型的教学性描述。
- 掩蔽使用情况。
- 测试可靠性评价。
- 与标准答案的差异。
- 教学反馈：本次做得好的地方、错误点、建议复习知识点。

报告中的“程度/性质/构型”应作为学习反馈，避免表述为真实医学诊断。

### 7.6 考核与评分

评分由结果评分和过程评分组成。

建议默认权重：

| 维度 | 分值 | 评价内容 |
| --- | ---: | --- |
| 测前准备 | 15 | 问诊、耳镜信息、说明任务、较好耳判断、换能器准备。 |
| 气导流程 | 20 | 频率顺序、熟悉化、升 5 降 10、阈值确认、1000 Hz 复测。 |
| 骨导流程 | 15 | 骨导频率、放置逻辑、非耳特异性认识、骨导限制。 |
| 掩蔽判断 | 20 | 识别交叉听觉风险、选择非测试耳、设置噪声、平台判断。 |
| 数据质量 | 15 | 阈值误差、漏测、无反应标记、可靠性备注。 |
| 报告解释 | 15 | PTA、程度、性质、构型、教学性建议。 |

自动扣分示例：

- 关键频率漏测。
- 阈值与标准答案差异超过教师设定容差。
- 未在必要场景使用掩蔽。
- 掩蔽耳选反。
- 把未掩蔽骨导当作明确单耳骨导。
- 1000 Hz 前后复测差异大但未处理。
- 长时间反复给高强度声音导致模拟患者疲劳或不适。
- 报告中结论与听力图不一致。

### 7.7 教学功能

练习模式提供分层提示：

- 轻提示：提示“当前频率可能需要确认阈值”。
- 中提示：指出“已响应后通常应下降强度再重新上升”。
- 强提示：展示本步骤推荐操作和原因。

复盘功能：

- 时间轴回放每次给声、频率、强度、耳别、换能器、掩蔽水平和响应。
- 标记错误节点。
- 对比学生听力图和标准听力图。
- 自动生成“待复习知识点”：例如耳间衰减、平台法、气骨导差、听力图符号。

教师功能：

- 创建课程和病例组。
- 设定病例是否随机、是否限时、是否允许提示。
- 编辑评分权重和误差容限。
- 查看班级统计和个体报告。

## 11. 关键算法边界

### 11.1 阈值判定

MVP 可在教学引擎中支持常规手动纯音测听逻辑：

- 熟悉化：通常从 1000 Hz 开始，给出明显可听刺激。
- 阈值搜索：未响应则上升，响应后下降，再从不可听强度上升。
- 阈值确认：同一强度在上升序列中达到设定响应比例后确认。
- 默认步进：上升 5 dB，下降 10 dB。

系统不应强制唯一流程。教师应能配置本校课程采用的流程细节。

### 11.2 掩蔽教学模型

MVP 的掩蔽模型要满足教学目标：

- 让学生能看见“未掩蔽阈值可能来自非测试耳”的后果。
- 让学生通过提高非测试耳噪声寻找平台。
- 能识别过度掩蔽和交叉掩蔽风险。

第一版不追求覆盖所有临床复杂情况，但每个简化处都应在教师文档中说明。

### 11.3 可靠性判断

系统可根据以下指标生成可靠性评价：

- 1000 Hz 复测差异。
- 同一阈值点确认次数。
- 假阳性响应数量。
- 明显超阈值未响应次数。
- 测试耗时和疲劳状态。
- 报告备注是否解释异常数据。

## 12. 交互界面草案

主界面分为四个区域：

1. 顶部：病例信息、当前模式、计时、提交报告。
2. 左侧：模拟听力计控制面板。
3. 中间：患者隔声室视图、患者响应灯、指令/对讲按钮。
4. 右侧：工作听力图、阈值表、教学提示。

考试模式隐藏教学提示，仅保留必要设备状态和记录区域。

## 13. 验收标准

MVP 完成后，应满足：

1. 学生可以完整完成至少 12 个内置病例的气导/骨导测试。
2. 患者响应与隐藏阈值、可靠性和掩蔽设置一致。
3. 每次给声和响应均写入事件日志。
4. 听力图符号、无反应标记和掩蔽记录能正确显示。
5. 系统能生成模拟报告和评分。
6. 教师能查看学生报告、分数和事件回放。
7. 核心算法有单元测试：响应概率、交叉听觉、掩蔽平台、评分扣分。
8. 关键界面在桌面浏览器中无明显遮挡和布局错乱。

## 14. 风险与控制

| 风险 | 控制措施 |
| --- | --- |
| 学生误以为系统报告可用于临床 | 全站和报告显著标注“教学模拟”。 |
| 掩蔽模型过度简化导致误学 | 教师文档说明简化边界，病例反馈中解释真实临床需遵循本地规范。 |
| 随机患者反应影响考试公平 | 考试模式固定随机种子，保证同病例可复现。 |
| 题库病例质量不足 | 病例需教师审核，隐藏答案和解释分离维护。 |
| 自动评分误判 | 教师可复核和调整分数，保留事件日志。 |
| 隐私问题 | MVP 不使用真实患者身份数据；若后续导入真实数据，需脱敏和权限控制。 |

## 15. 开发阶段计划

### 阶段 1：原型和核心引擎

- 搭建前端项目。
- 实现病例数据结构。
- 实现模拟听力计基本控制。
- 实现患者反应引擎。
- 实现听力图绘制。
- 内置 3 个病例验证流程。

### 阶段 2：完整 MVP

- 完成 12 个内置病例。
- 加入骨导、掩蔽、无反应。
- 实现报告生成。
- 实现练习提示和错误解释。
- 实现评分引擎。

### 阶段 3：教师端

- 病例管理。
- 考试发布。
- 成绩统计。
- 过程回放。
- 导出报告。

### 阶段 4：扩展模块

- 言语测听。
- 声导抗结果阅读训练。
- 儿童测听变体。
- 多人课堂部署。
- 课程知识点和题库联动。

## 17. 待确认问题

开发前建议由项目负责人或教师确认：

1. 第一版是否只做纯音测听，还是必须同时包含言语测听。
2. 本校课程采用的具体阈值判定和掩蔽教学流程。
3. 听力损失程度分类采用哪套教材标准。
4. 是否需要教师账号和班级管理，还是先做单机练习版。
5. 是否需要中文/英文双语界面。
6. 报告导出格式：网页、PDF、Excel 或课程平台导入格式。
7. 是否允许学生在练习中看到实时标准答案或只看步骤提示。
